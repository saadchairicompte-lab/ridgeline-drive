# Ridgeline Drive

Open-world browser racing game (Three.js). Play: https://saadchairicompte-lab.github.io/ridgeline-drive/

**Phone as a steering wheel:** open the game on a computer, scan the QR code on the start screen with your phone
(or open the page on the phone and enter the 4-digit code), then tap *Use this phone as a steering wheel*.
Tilt the phone to steer; Gas and Brake are on the screen edges. Phone and computer talk directly over WebRTC
(PeerJS), paired through the public PeerJS broker.

This is a copy of the game's source, which lives in the "racing game" Claude project (`racing-game/`).
